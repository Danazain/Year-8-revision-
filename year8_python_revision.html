🎯 School Club Challenge

Write a program that (1) asks for a name, (2) asks for an age using int(input()), (3) stores three clubs in a list, (4) uses if, elif and else, and (5) prints the student's name and first club.

Age under 11 → Junior Club. Age 11–13 → Middle School Club. Age 14 or above → Senior Club.

Starter code – fill in the blanks

name = input("Enter your name: ")
age = __________
clubs = ["Coding", "Art", "Music"]

if age < 11:
    print("Junior Club")
elif __________:
    print("Middle School Club")
else:
    print("Senior Club")

print("Welcome", ______)
print("First club:", clubs[___])
